DSH Desktop

Una aplicación de escritorio Windows comunitaria para DeepSeek Harness (dsh): runtime de Node.js integrado, cero dependencias, instalación de un clic, 11 plugins comunitarios preinstalados.

¿Qué es esto?

Convierte DeepSeek Harness de una herramienta de línea de comandos en una aplicación de escritorio que abres con doble clic.

📦

Totalmente autocontenido

Incluye Node.js 22 LTS portátil, el motor dsh y pnpm. Tu equipo no necesita Node.js ni ninguna herramienta de desarrollo: instala y listo.

🖱️

Instalación de un clic

Instalador NSIS en tu carpeta de usuario, sin permisos de administrador. El primer inicio extrae el runtime automáticamente (1–3 min, solo una vez); los inicios siguientes tardan unos 8 segundos.

🧩

11 plugins preinstalados

Mesa de trabajo de proyectos, memoria a largo plazo, mercado integrado, puente visual, búsqueda web sin clave, equipos multiagente, estadísticas de contexto, emparejamiento con el móvil, terminal UI… todo listo al instalar.

🫥

Residente en la bandeja

Cerrar la ventana solo minimiza a la bandeja. Desde el menú de la bandeja: reiniciar el motor, abrir la terminal TUI, ir al espacio de trabajo o a los registros.

🔒

Datos solo locales

Tu clave de API y todos los datos viven en %APPDATA%\DSH Desktop\. El motor solo escucha en loopback (127.0.0.1) con token de acceso; las operaciones de archivos del agente se limitan al espacio de trabajo que elijas.

🎨

Marca original

Sigue las guías de marca oficiales: la abreviatura DSH recomendada por el ecosistema y un monograma original "DSH_" en azul DeepSeek (#4D6BFE). No se usa el logo oficial.

Funciona en 3 pasos

Sin terminal (excepto para plugins en la versión Lite).

  1. Instalar: doble clic en el instalador. Se instala en tu carpeta de usuario (%LOCALAPPDATA%\Programs) y crea los accesos directos de "DSH Desktop" en el escritorio y el menú Inicio.
  2. Primer inicio: pega tu clave de API de DeepSeek (consíguela en platform.deepseek.com), mantén o cambia la carpeta de trabajo y pulsa Iniciar.
  3. Usar: se abre la Web UI — conversa, crea proyectos, ejecuta tareas. Cerrar la ventana solo minimiza a la bandeja; para salir del todo usa el menú de la bandeja.

Instalar plugins en Lite: ejecuta "%APPDATA%\DSH Desktop\runtime\bin\dsh.cmd" plugin --profile web add @dsh-market/plugin y reinicia la aplicación para obtener el marketplace. Más detalles en las notas de la versión Lite.

Arquitectura

Shell de escritorio + motor integrado, con límites de proceso claros y una desinstalación limpia.

┌─ Ventana Electron ────── carga http://127.0.0.1:<puerto> (DSH Web UI)
│    · dsh-worktable: cajón lateral + paneles acoplables + sala de control
│    · @dsh-market/plugin: marketplace (instala más plugins en línea)
├─ Proceso principal ───── ciclo de vida / bandeja / asistente inicial / registros
│    └─ hijo: runtime\bin\dsh-web.cmd (lanzador generado)
└─ Motor integrado ─────── Node 22 LTS portátil + @deepseek-ai/dsh + pnpm
     └─ carpeta de datos %APPDATA%\DSH Desktop\ (extrae vendor.zip al primer inicio)
Notas de seguridad: el motor solo escucha en loopback (127.0.0.1) con token de acceso; los enlaces externos siempre se abren en el navegador del sistema; las llamadas a procesos hijos usan validación de rutas con lista blanca.

Preguntas frecuentes

¿No encuentras tu respuesta? Pregunta en Issues.

¿Necesito instalar Node.js antes?

No. El runtime (Node 22 LTS + dsh + pnpm) viene dentro del instalador. No se necesita ningún entorno de desarrollo en tu equipo.

¿Completa o Lite, cuál elijo?

Elige la Completa para todo listo al instalar; la Lite si prefieres algo ligero y elegir plugins uno a uno. El núcleo es idéntico, y la Lite puede instalar cualquier plugin (incluido el marketplace) con el CLI incluido cuando quieras.

¿Dónde se guarda mi clave de API? ¿Es segura?

Localmente, en %APPDATA%\DSH Desktop\dsh-home\.env. Solo la usa el motor de tu máquina para llamar a la API del modelo, sin intermediarios. No compartas ese archivo; rota las claves de prueba en la plataforma de DeepSeek al terminar.

¿Por qué archify / aegis / agent-teams están inactivos por defecto?

Tienen incompatibilidades de API con el dsh 0.1.2-rc.1 incluido que bloquearían el motor, así que se instalan pero quedan inactivos. Los archivos están presentes; actívalos en la aplicación cuando el proyecto original los adapte.

¿Cómo desinstalo por completo?

Desinstala DSH Desktop desde Configuración → Aplicaciones de Windows (los accesos directos también se eliminan). La carpeta de datos %APPDATA%\DSH Desktop\ se conserva por defecto (contiene tu clave e historial): bórrala manualmente si ya no la necesitas.

¿Es esta la aplicación oficial de DeepSeek?

No. DSH Desktop es un proyecto comunitario independiente, sin afiliación con DeepSeek. Usa la abreviatura DSH recomendada por el ecosistema y un icono original, siguiendo las guías de marca de DeepSeek Harness.
