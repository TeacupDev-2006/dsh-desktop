DSH Desktop

为 DeepSeek Harness（dsh）打造的社区 Windows 桌面端：内置 Node.js 运行时，零依赖、一键安装，预装 11 个社区插件。

这是什么？

把 DeepSeek Harness 从「命令行工具」变成「双击即用的桌面应用」。

📦

运行时完全自包含

内置便携 Node.js 22 LTS、dsh 引擎与 pnpm。你的电脑不需要安装 Node.js 或任何依赖，解压即用。

🖱️

一键安装

NSIS 安装包装到用户目录，无需管理员权限；首次启动自动解压运行时（约 1–3 分钟，仅一次），之后每次启动约 8 秒。

🧩

预装 11 个社区插件

项目工作台、长期记忆、插件市场、视觉桥接、免 key 联网搜索、多智能体团队、上下文统计、手机扫码、终端 UI 等，装完即有。

🫥

托盘常驻

关闭窗口即最小化到托盘。托盘菜单可重启引擎、打开 TUI 终端、直达工作区与日志目录。

🔒

数据全在本机

API Key 与所有数据保存在本机 %APPDATA%\DSH Desktop\，不经过任何第三方服务器；Agent 文件操作限定在你选择的工作区内。

🎨

原创品牌设计

遵循 DSH 官方品牌规范：使用生态推荐的 DSH 缩写与原创 "DSH_" 字标（DeepSeek 品牌蓝 #4D6BFE），不使用官方 logo。

三步上手

全程无需命令行（精简版装插件除外）。

  1. 安装：双击安装包，自动装入用户目录（%LOCALAPPDATA%\Programs），桌面与开始菜单创建「DSH Desktop」快捷方式。
  2. 首次配置：启动后粘贴 DeepSeek API Key（在 platform.deepseek.com 获取），选择或保持默认工作区目录，点击「启动」。
  3. 开始使用：Web UI 出现后即可对话、写项目、跑任务。关闭窗口只是最小化到托盘，引擎保持运行；彻底退出请用托盘菜单。

精简版安装插件：在命令行执行 "%APPDATA%\DSH Desktop\runtime\bin\dsh.cmd" plugin --profile web add @dsh-market/plugin，重启应用即获得插件市场；更多插件说明见 精简版 Release。

架构一览

桌面壳 + 内置引擎，进程边界清晰，卸载干净。

┌─ Electron 窗口 ───────── 加载 http://127.0.0.1:<port>（DSH Web UI）
│    · dsh-worktable：侧边栏抽屉 + 可停靠分屏 + 控制室看板
│    · @dsh-market/plugin：插件市场（可继续在线装插件）
├─ Electron 主进程 ─────── 生命周期 / 托盘 / 首启引导 / 日志
│    └─ 子进程：runtime\bin\dsh-web.cmd（构建期生成的启动器）
└─ 内置引擎 ────────────── 便携 Node 22 LTS + @deepseek-ai/dsh + pnpm
     └─ 数据目录 %APPDATA%\DSH Desktop\（首启自解压 vendor.zip）
安全设计：引擎只监听本机环回地址（127.0.0.1）并带访问令牌；外部链接一律跳系统浏览器打开；子进程调用全部使用白名单路径校验。

常见问题

没找到答案？去 Issues 提问。

需要先安装 Node.js 吗？

不需要。运行时（Node 22 LTS + dsh + pnpm）全部内置在安装包里，安装完成后电脑上不需要任何开发环境。

完整版和精简版怎么选？

想开箱即用选完整版；想控制体积、按需挑选插件选精简版。两者内核完全一致，精简版随时可通过内置 CLI 补装任意插件（包括插件市场本身）。

API Key 存在哪里？安全吗？

保存在本机 %APPDATA%\DSH Desktop\dsh-home\.env，仅用于本机引擎调用模型 API，不经过任何第三方。请勿把该文件分享给他人；若是测试用的 Key，用完建议在 DeepSeek 平台轮换。

为什么 archify / aegis / agent-teams 默认没启用？

实测它们与内置 dsh 0.1.2-rc.1 存在 API 兼容问题，启用会导致引擎启动失败，所以默认安装但未激活。文件都在，待上游适配后可在应用内启用。

如何彻底卸载？

系统「设置 → 应用」中卸载 DSH Desktop 即可（同时清理快捷方式）。数据目录 %APPDATA%\DSH Desktop\ 默认保留（含 API Key 与工作记录），确认不再需要可手动删除。

这是 DeepSeek 官方的应用吗？

不是。DSH Desktop 是独立的社区项目，与 DeepSeek 官方无隶属关系；命名使用生态推荐的 DSH 缩写、图标为原创设计，遵循 DeepSeek Harness 官方品牌使用规范。
