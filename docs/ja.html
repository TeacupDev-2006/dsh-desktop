DSH Desktop

DeepSeek Harness（dsh）向けのコミュニティ Windows デスクトップアプリ：Node.js ランタイム内蔵で依存ゼロ・ワンクリックインストール、コミュニティプラグイン 11 件を同梱。

これは何？

DeepSeek Harness を「コマンドラインツール」から「ダブルクリックで使えるデスクトップアプリ」に。

📦

ランタイム完全内蔵

ポータブル Node.js 22 LTS・dsh エンジン・pnpm を同梱。お使いの PC にNode.js や開発環境は一切不要です。

🖱️

ワンクリックインストール

ユーザーフォルダーへの NSIS インストールで管理者権限不要。初回起動時にランタイムを自動展開（1〜3 分・一度だけ）、2 回目以降は約 8 秒で起動。

🧩

プラグイン 11 件同梱

プロジェクトワークテーブル、長期記憶、プラグインマーケット、ビジュアルブリッジ、キー不要の Web 検索、マルチエージェント、コンテキスト統計、スマホ連携、ターミナル UI をすぐ使えます。

🫥

トレイ常駐

ウィンドウを閉じてもトレイに最小化。トレイメニューからエンジン再起動・TUI ターミナル起動・ワークスペースやログフォルダーを開けます。

🔒

データはローカルのみ

API キーと全データは %APPDATA%\DSH Desktop\ に保存。エンジンはループバック（127.0.0.1）のみでトークン付きで待機し、エージェントのファイル操作は選択したワークスペース内に制限されます。

🎨

オリジナルブランド

上流のブランドガイドラインに従い、エコシステム推奨の DSH 略称とオリジナルの "DSH_" ワードマーク（DeepSeek ブルー #4D6BFE）を使用。公式ロゴは使用していません。

3 ステップで開始

コマンドライン不要（Lite 版へのプラグイン追加を除く）。

  1. インストール：セットアップをダブルクリック。ユーザーフォルダー（%LOCALAPPDATA%\Programs）にインストールされ、デスクトップとスタートメニューに「DSH Desktop」のショートカットが作成されます。
  2. 初期設定：起動後に DeepSeek API キー（platform.deepseek.com で取得）を貼り付け、ワークスペースフォルダーを選んで「起動」をクリック。
  3. 利用開始：Web UI が表示されたらチャット・プロジェクト作成・タスク実行が可能。ウィンドウを閉じるとトレイに最小化され、エンジンは起動し続けます。完全終了はトレイメニューから。

Lite 版へのプラグイン追加："%APPDATA%\DSH Desktop\runtime\bin\dsh.cmd" plugin --profile web add @dsh-market/plugin を実行してアプリを再起動するとマーケットが使えます。詳細は Lite 版 Release を参照。

アーキテクチャ

デスクトップシェル + 内蔵エンジン。プロセス境界が明確で、アンインストールもクリーンです。

┌─ Electron ウィンドウ ─── http://127.0.0.1:<port>（DSH Web UI）をロード
│    · dsh-worktable：サイドバードロワー + ドッキング分割 + コントロールルーム
│    · @dsh-market/plugin：マーケット（追加プラグインをオンラインでインストール）
├─ Electron メイン ─────── ライフサイクル / トレイ / 初回ウィザード / ログ
│    └─ 子プロセス：runtime\bin\dsh-web.cmd（ビルド時生成のランチャー）
└─ 内蔵エンジン ────────── ポータブル Node 22 LTS + @deepseek-ai/dsh + pnpm
     └─ データディレクトリ %APPDATA%\DSH Desktop\（初回起動で vendor.zip を展開）
セキュリティ設計：エンジンはループバック（127.0.0.1）のみでトークン付き待機。外部リンクは常にシステムブラウザーで開き、子プロセス呼び出しは許可リストによるパス検証を行います。

よくある質問

解決しない場合は Issues へどうぞ。

Node.js のインストールは必要？

不要です。ランタイム（Node 22 LTS + dsh + pnpm）はすべてインストーラーに同梱されており、開発環境は一切不要です。

完全版と Lite 版、どちらを選ぶ？

すぐ使いなら完全版、軽量にしてプラグインを自分で選ぶなら Lite 版。コアは完全に同一で、Lite 版でも内蔵 CLI でいつでも任意のプラグイン（マーケット自体も）追加できます。

API キーはどこに保存される？安全？

%APPDATA%\DSH Desktop\dsh-home\.env にローカル保存され、モデル API の呼び出しにのみ使われます。第三者サーバーは経由しません。ファイルの共有は避け、テスト用キーは DeepSeek プラットフォームでローテーションしてください。

archify / aegis / agent-teams が既定で無効なのはなぜ？

内蔵 dsh 0.1.2-rc.1 との API 互換性問題で有効化するとエンジンが起動しないため、同梱のみで既定は無効です。ファイルは配置済みで、上流の対応後にアプリ内で有効化できます。

完全にアンインストールするには？

Windows の「設定 → アプリ」から DSH Desktop をアンインストールしてください（ショートカットも削除されます）。データフォルダー %APPDATA%\DSH Desktop\ は既定で残ります（API キーと履歴を含む）。不要なら手動で削除してください。

これは DeepSeek 公式アプリ？

いいえ。DSH Desktop は独立したコミュニティプロジェクトで、DeepSeek 公式とは関係ありません。エコシステム推奨の DSH 略称とオリジナルアイコンを使用し、DeepSeek Harness ブランドガイドラインに従っています。
